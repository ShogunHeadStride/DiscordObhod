## ⚙️Использование

1. Активируйте Безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется.
    * На роутерах Keenetic включите опцию "Транзит запросов". При ее отключении Secure DNS на компьютере может работать некорректно.

2. Получите zip/rar-архив на [странице последнего релиза](https://github.com/ShogunHeadStride/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и отметьте "Разблокировать". При распаковке через 7-Zip или PeaZip действие не требуется.

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите нужный скрипт:
    * Для поиска подходящей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для добавления стратегии в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск выбранной стратегии.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **переберите разные варианты (ALT, FAKE и другие), пока не найдется подходящий**.

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** - удаляет стратегию и WinDivert из служб.
  - **`Check Status`** - показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** - включает или отключает отдельный режим для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения режима стратегию нужно запустить заново.**  
  Текущее состояние отображается в скобках.
  - **`IPSet Filter`** - меняет режим обработки сервисов, перечисленных в `ipset-all.txt`.  
  Это полезно при проверке ресурса, который без zapret открывается, а с ним работает неправильно.  
  В скобках показан текущий режим:
    - `none` - IP-адреса не проверяются
    - `loaded` - адрес проверяется на наличие в списке
    - `any` - фильтруется любой IP-адрес
  - **`Auto-Update Check`** - включает или отключает автоматическую проверку обновлений.
  - **`Replace active fakes`** - меняет используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** - загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения Discord к голосовому чату**</ins>.
  - **`Check for Updates`** - вручную ищет обновления.
  - **`Run Diagnostics`** - проверяет распространенные причины неисправности zapret.  
  В конце можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно сломавшийся Discord к работе.
  - **`Run Tests`** - запускает проверку стратегий:
    - `Standard tests` - тестирует сайты из `utils/targets.txt`.
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если установленный hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - От имени администратора откройте текстовым редактором файл `hosts` в созданном каталоге.
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните файл и проверьте соединение. При отсутствии результата убедитесь, что файл действительно был сохранен.

#### Результат не гарантируется. Если способ не помог, установите [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/ShogunHeadStride/tg-ws-proxy) либо любой публичный прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Рабочая стратегия может со временем перестать работать.**
> Обнаружение параметров способно сделать неэффективной стратегию, которая раньше работала.
> Здесь собрано много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из имеющихся и измените ее параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что в `service.bat` -> `Run Diagnostics` нет ошибок.

- Проверьте наличие адреса ресурса в списках доменов или IP-адресов.

- Запустите другие варианты (**`ALT`**, **`FAKE`** и прочие).

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация есть в [#765](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues/765).

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y.
- Удалите каталог zapret.
- Загрузите свежую версию со [страницы релизов](https://github.com/ShogunHeadStride/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть пункт разблокировки, отметьте его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов.
- По очереди запускайте разные скрипты `general`. Проверяйте нужные интернет-ресурсы; если они не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию.
- После нахождения рабочего варианта добавьте его в автозапуск: `service.bat` -> `Install Service` -> выберите стратегию.

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Используйте инструкцию https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide.

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноименными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. В командной строке Windows (Win+R, `cmd`) найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если рабочая стратегия перестала помогать, проверьте остальные варианты.
- См. также [#251](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите ее.
- В `service.bat` выберите `Run Diagnostics`, затем очистите кэш Discord.
- После очистки проверьте приложение Discord.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно используйте ее.
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Установите [tg-ws-proxy](https://github.com/ShogunHeadStride/tg-ws-proxy).
- Либо подключитесь к бесплатному MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Общий порядок действий:
- обновите ipset через `service.bat` и активируйте `Game Filter`;
- если результата нет, дополнительно включите `ipset any`.

Учитывайте, что режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включенным постоянно: определите все IP-адреса игры и добавьте их в `ipset-all.txt`.

Если это не помогло, создайте обсуждение в разделе [Discussions](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите ее [здесь](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** - домены-исключения, например когда сеть уже есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется.
- **`ipset-all.txt`** - IP-адреса и подсети.
- **`ipset-exclude-user.txt`** - IP-адреса и подсети-исключения.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
